# [Path Planning] A New Hybrid Grey Wolf Optimization Algorithm for Drone Trajectory Planning [with MATLAB Code]

Introduction: The development of unmanned flight technology is an inevitable trend in many countries [1, 2]. Drones, as a modern aviation weapon system, are increasingly valued due to their potential for operating in complex and hazardous environments [3]. Trajectory planning design is an important mission in the mission planning system of drones, requiring a safe and efficient flight route from the initial position to the desired destination under specific constraints [4]. Therefore, the problem of flight path planning can be seen as a complex optimization problem that requires efficient algorithms to solve. As an effective method for solving optimization problems, intelligent algorithms have been applied in various fields, such as sustainable maneuverability projects [5-9], sustainable manufacturing [10-12], replenishment modeling and optimal batches [15, 16], and supply chain design networks [17-24]. Metaheuristic algorithms are natural-inspired intelligent algorithms [25, 26] meaning they originate from mimicking physical phenomena or biological interactions. Metaheuristic optimization algorithms can solve complex optimization problems by searching for a set of related parameter values through minimizing or maximizing the objective function [27]. A series of metaheuristic algorithms have been used to solve the path planning problem. For example, reference [28] proposed a new multi-frequency vibration genetic algorithm (mVGA) to solve the drone path planning problem. Reference [29] transformed the drone path planning problem into an extended traveling salesman problem (TSP) and proposed an improved discrete particle swarm optimization algorithm (DPSO) to solve the problem. Reference [30] proposed a chaotic artificial bee colony algorithm to solve the trajectory planning problem for unmanned combat aircraft (UCAV). Reference [31] proposed an improved differential evolution algorithm to obtain feasible global flight routes for drones. Reference [32] proposed a multi-drone path planning algorithm based on social class pigeons and established a time-stamped segmented path planning model to simplify the handling of multi-drone coordination costs. To complete the scouting mission of a drone group, reference [33] proposed multiple distributed particle swarm optimization path planning algorithms.
The Grey Wolf Optimization Algorithm (GWO) is a novel metaheuristic algorithm proposed by Mirjalili et al. in 2014. The algorithm mimics the hunting behavior and social leadership of grey wolves, which makes it highly exploratory [34]. Compared to other metaheuristic algorithms, GWO has advantages such as flexibility, simplicity, and ease of implementation. As an efficient and competitive optimization algorithm, GWO has been applied to solve many engineering applications and control problems, including economic load allocation problems [35], PID controller design [36], multi-tracking target [37], and wide-area power system stabilizer design [38].
The Coevolutionary Search Algorithm (SOS) was initially developed by Cheng and Prayogo [39] in 2014, based on the symbiotic interactions between organisms in ecosystems. In SOS, offspring can be produced through symbiotic behaviors between current organisms and other random organisms or the best organism in the current ecosystem, which has great developmental potential [40]. Due to its ability to adjust parameters without modification and ease of implementation, SOS has been widely adopted [41].
In recent years, researchers have turned to a new technique called hybridization [42,43], which combines multiple metaheuristic algorithms for optimization. In this technique, skilled combinations can show more effective optimization when dealing with real-world problems [44]. To address the problem of multi-robot path planning, literature [45] improved the Particle Swarm Optimization Algorithm (PSO) and the Gravitational Search Algorithm (GSA), proposing a new hybrid algorithm IPSO-IGSA. Reference [46] introduced two hybrid methods based on Whale Optimization Algorithm (WOA) to design different feature selection problems. Literature [47] proposed a hybrid Particle Swarm Optimization Algorithm based on Mixed Teaching Learning to achieve better convergence. Literature [48] proposed a new hybrid Particle Swarm Optimization-Generalized Particle Swarm Optimization method to solve unit commitment problems. At the same time, the effectiveness of this method was analyzed through experiments. The results indicate that the algorithm proposed in this paper is effective.
Additionally, convergence analysis is an important metaheuristic algorithm to demonstrate its stability. Reference [49] proposed a new hybrid algorithm that combines Particle Swarm Optimization (PSO), Genetic Algorithm (GA), and Sequential Order Search Algorithm (SOS). The algorithm's correction reciprocal phase was proven to converge better to the minimum value through mathematical induction. Reference [50] introduced an improved Gravitational Search Algorithm (IGSA) to solve optimization problems. They used discrete-time linear system theory to prove the stability of IGSA. Reference [51] proposed an improved Center Force Optimization Algorithm (MCFO) and conducted a convergence analysis on the algorithm using linear difference equations. However, there is currently a lack of research on the convergence analysis of GWO and its hybrid algorithms.
Metaheuristic algorithms need to strike a good balance between exploration and exploitation operations to effectively achieve both global and local search. The optimization mode of the GWO algorithm has great development capability. In contrast, the SOS algorithm has local development capabilities. At the same time, both GWO and SOS algorithms show the potential to improve performance when mixed with other metaheuristic algorithms. Therefore, we combined the hunting and exploiting abilities of wolves and organisms to propose a new hybrid optimization algorithm called HSGWO-MSOS algorithm. This algorithm calculates the optimal flight path for drones offline and uses cubic B-spline curves for smoothing. The main innovations of this paper are summarized as follows:
· A new hybrid algorithm HSGWO-MSOS was proposed, which consists of a simplified GWO stage and an improved SOS stage.
· Based on the inspiration of linear difference equations, the algorithm was analyzed for convergence.
· The HSGWO-MSOS algorithm was applied to the problem of drone path planning and compared with other classical algorithms, achieving good experimental results.
Conclusion: In response to the issue of trajectory planning for drones in complex and dangerous areas, a new hybrid Grey Wolf Optimization Algorithm (HSGWO-MSOS) is proposed. This algorithm effectively combines the exploratory and exploitative capabilities of the GWO and SOS algorithms. It simplifies the stages of the GWO algorithm, accelerates convergence speed, while maintaining the population's exploration ability. The cohabitation phase of the SOS algorithm is improved, enhancing its usability. Furthermore, the convergence analysis of the HSGWO-MSOS algorithm is conducted using linear difference equations. Additionally, the generated trajectories are smoothed with cubic B-spline curves, making the planned flight paths more suitable for drones. Experimental results demonstrate that the HSGWO-MSOS algorithm can successfully obtain effective and safe flight routes. It is compared with the GWO, SOS, and SA algorithms, validating the superiority of the HSGWO-MSOS algorithm in solving the problem of drone route planning.
